# Estrazione TAG — Indizi
Stai leggendo il modulo avventura e devi estrarre dal testo gli `indizi` utili alla conduzione.
Un `indizio` è un reperto, documento, simbolo, informazione, traccia o fatto osservabile che può guidare i PG verso una scoperta, una indagine o una rivelazione.

Rispondi SOLO con JSON valido nel formato:
{
  "tags": [
    {
      "canonical": "nome indizio",
      "aliases": ["alias 1"],
      "evidence": "breve motivo"
    }
  ]
}

Regole:
Un indizio valido può essere:
- un reperto fisico (esempio: una scatola di cerini con una nota, la chiave della stanza, fotografia bruciata a metà), 
- un documento o appunto (esempio: la lettera del testamento, un biglietto nela tasca del morto, lettera macchiata di sangue, mappa del tunnel)
- un simbolo o segno riconoscibile (esempio: il tatuaggio del drago, la croce nordica)
- una traccia osservabile (esempio: le impronte del mostro, tracce di sangue nel pavimento)
- un'informazione concreta utile all'indagine (il tesoros i trova sull'isola, John non è morto)

- includi solo indizi esplicitamente presenti nel testo
- escludi atmosfera, tono, emozioni e semplici dettagli decorativi
- se nel testo compaiono più indizi validi, estraili tutti
- usa in `canonical` la forma più chiara e completa presente nel testo
- metti in `aliases` solo varianti esplicite davvero presenti nel testo
- se il testo corrisponde chiaramente a un indizio già noto, riusa il `canonical` già noto
- se non ci sono indizi validi, restituisci un array vuoto

Confronta i tuoi indizi con quelli già identificati per questo modulo:
[
  {
    "canonical": "appunto irrilevante di Belloq",
    "aliases": [
      "Timeo 25a — non è metafora"
    ]
  },
  {
    "canonical": "rapporto sugli ultimi movimenti di Belloq",
    "aliases": []
  },
  {
    "canonical": "tavoletta di pietra con incisioni sconosciute",
    "aliases": []
  }
]

- se lo stesso indizio è già presente evita di metterlo in output
- se riscontri una similutudine tra il tuo indizio e uno già presente, puoi mettere le variante tra gli `aliases`
- non forzare corrispondenze dubbie con i tag già noti


Testo:
Guida i PG verso questi punti senza forzarli:

collegare Belloq alla tavoletta, a Sophia e al Timeo;
trovare il deposito alla Gare du Nord;
capire che Knossos è la destinazione;
scoprire che i nazisti stanno già partendo;
chiudere l’Atto I con una decisione urgente: inseguimento, anticipo o fuga verso Creta.
Regola di conduzione

Il mondo si muove anche senza i PG. Se esitano, i nazisti avanzano. Non bloccare mai l’indagine dietro un solo tiro o un solo nodo: ogni rivelazione importante deve poter emergere da più percorsi. Mantieni pressione, chiarezza degli indizi e senso di corsa contro il tempo.
